## 6. التفسيرات المعتمدة

- **الموقع:** يظهر `WWW.SIRAJPROPERTIES.NET` على القرطاسية والعروض وتوقيع البريد والمستندات فقط. المنشورات والقصص والخواتيم تكتفي بالهاتف وإنستجرام، التزاماً بالقاعدة السابقة.
- **اسم المشروع:** لا يُكتب «سراج» نصاً كاسمٍ للمشروع، ولا تُستخدم أي مخطوطة حتى اعتماد معالجة جديدة. حيث كانت المخطوطة، حلّ محلها سطر معتمد («أوّلُ الضوء.»، «في قلب المدينة، بيتٌ من ضوء.»، «مدروسة في كل تفاصيلها.») أو «مسقط» مع الوصف. يبقى السطر المعتمد «حين يحلّ المساء، يُضيء سراج.» نصاً إعلانياً كما اعتُمد.
- **الحزم الثقيلة:** حُزم ZIP لا تُحفظ في Git (حدّ GitHub للحجم)، وتُبنى بالأمر `npm run build:kit`.

## 8. نقاط مفتوحة تحتاج قراراً أو تدخلاً بشرياً

0. **معالجة جديدة لاسم المشروع** (بعد إلغاء مخطوطة «مشروع سراج»)، ومعها نسخ الافتتاحية والخاتمة الخاصة بالمشروع.
1. **البيانات القانونية والتجارية:** رقم السجل التجاري، والرقم الضريبي، والعنوان الكامل، والبيانات البنكية. عرض السعر والفاتورة الضريبية والإيصال وغلاف العقد معزولة إلى حين توفّرها.
2. **أسماء ومسمّيات الموظفين** لبطاقات العمل والتوقيعات؛ القوالب حالياً تعرض «الاسم / المسمى الوظيفي».
3. **أسعار المشروع ومساحاته وعدد وحداته ومواعيده:** القوالب تعرض «—»، والمواد العامة تحذفها.
4. **استضافة صور توقيع البريد** على خادم بريد الشركة، ثم ضبط `email.logo_url`.
5. **رفع الحزم الثنائية الكبيرة (ZIP) إلى مجلدات Drive:** الحزم في `21-Brand-Kit/` جاهزة؛ يلزم رفعها يدوياً إلى مجلداتها (اسم كل حزمة يبدأ برقم المجلد).
6. **المراجعة البصرية النهائية من العميل** للافتتاحية والخاتمة الرسميتين.
