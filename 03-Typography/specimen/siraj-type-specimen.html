Western digits are used everywhere, including Arabic text, so that prices, areas and dates read identically in both languages. The SIRAJ Digits face maps Jost figures onto the digit code points and is loaded ahead of Tajawal. Use tabular lining figures in tables, and never use Arabic-Indic digits (٠١٢٣).

The thousands separator is a comma and the decimal mark is a point. Currency is written OMR before the amount in English and ر.ع. after it in Arabic.
