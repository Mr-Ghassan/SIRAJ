14 · Property Marketing — Project sub-brand

Project name + “by SIRAJ” endorsement

Every SIRAJ development carries its own name, set quietly in Jost Light and Tajawal Light, and is always endorsed by the SIRAJ wordmark. The project leads; SIRAJ signs. One construction serves all projects, so a portfolio reads as one family.

HierarchyProject name first, SIRAJ second. The endorsement is never larger than the project name and never stands above it.
NameLatin: Jost Light (300) uppercase, tracking .18em. Arabic: Tajawal Light (300), never tracked. No new logotypes, no bespoke letterforms per project.
DescriptorJost Medium at 16% of the name size, letter-spaced to the name width (max .62em; shorter descriptors are centred under the name). A built line, not a tagline.
Endorsement“BY” (Jost Medium) or «من تطوير» (Tajawal Medium) + the official SIRAJ wordmark at 30% of the name size, never wider than 30% of the name width. Always the master artwork, never retyped.
Clear space½ the name cap height on all sides. Minimum width: 40 mm print · 160 px screen (endorsement wordmark must stay ≥ 96 px / 25 mm on outdoor; otherwise place the SIRAJ logo separately).
ColourPrimary: Deep name, Maroon descriptor + wordmark on Ivory/Linen. Reversed: Ivory name, Sand descriptor + wordmark on Deep, Shadow or G1. White: on photography only.
