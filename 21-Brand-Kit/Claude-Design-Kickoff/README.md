# Claude Design kick-off pack · Foundation phase

Everything needed to start the SIRAJ foundation-phase work in Claude Design.

1. Read `00_PROMPT_Claude-Design_AR.md`. It has the setup steps, the attachment list and the prompt to paste.
2. Attach the folders `01`–`07`. The ★ items in the prompt file come first if uploads are limited.
3. Select the **SIRAJ Design System** (https://claude.ai/artifact/BAvFh5gJScMiQXApNnvBT7).

The renders in `05_Project-Siraj` are web-size (2400 px) copies of the 4K masters in `14-Property-Marketing/12-Project-Siraj/Source/Clean/`.

`SIRAJ_Claude-Design-Kickoff_v1.0.zip` (in `21-Brand-Kit/`) is the same pack zipped. Rebuild it with `bash tools/build-kit.sh`.
